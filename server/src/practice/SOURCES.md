# Practice problem sources

The first 13 problems were written for multiGO. They are intro, easy, and medium.

The problems whose ids start with `ggg-` are adapted from Go Game Guru's Weekly Go Problems.

- Authors: An Younggil 8p and David Ormerod
- Source: https://github.com/gogameguru/go-problems
- License: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (https://creativecommons.org/licenses/by-nc-sa/4.0/)
- What changed: the SGF trees were converted into this app's solution nodes. Variations that the source does not mark as correct were left out. The easy set is graded intermediate here, and the intermediate set is graded hard, so both sit after the hand-made medium problems.

`ggg.ts` is the adapted file and stays under that license. The conversion does not relicense the rest of the repository.
